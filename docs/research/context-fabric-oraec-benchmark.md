# Research — Actual ORAEC Text-Fabric versus Context-Fabric (#84)

Context-Fabric pinned commit `dd54b73255d19f9ce230e7785d391106f4b94df2`, core package `libs/core`, requires **Python >=3.13**. Native ORAEC writer/auditor remains on TF 13.1.0, raw source immutable `b83a0ee5fae27a40d4c0a2a9a8c9c2973d45e9cd`, 13,026 texts, 101,796 sentences, 815,026 words + 3 anchors, 2,930 native CR occurrence nodes, 65 canonical feature hashes and 105,254,838 TF feature bytes (baseline artifact 11742333778).

Verified code: `cfabric/core/fabric.py::load()` detects a **single-source** `.cfm/<version>/meta.json` and loads memory-mapped warp and computed CSR arrays without rerunning the Python `_precompute` routine; `loadAll()` additionally loads node/edge features. `Compiler(...).compile()` converts native text `.tf` files to `.cfm`, including recomputing the SAME original `levUp` posting-set intersections in `cfabric/precompute/prepare.py::levUp`. Initial compilation is therefore NOT automatically faster; repeated load is the benefit and compiler CPU/storage must be counted separately. The library README claims 11x faster BHSA loading but that is not measured on ORAEC and must not be presented as evidence for ORAEC. CFM's optional embedding preload trades memory for query speed.

Method: one GitHub Actions Linux Python 3.13 runner; exact pinned upstream source, writer output, full original cache-free tf-build validation, separate independent raw→TF graph conservation and advanced app before compiled experiment. Then separately measured fresh-process original native TF `loadAll` and Context-Fabric `Compiler` fresh `.cfm`, then 3 *fresh-process* Context-Fabric `loadAll` repetitions, all loading same 65-feature corpus. Capture per-process wall/CPU/Linux RSS high-water, CFM byte size, and streaming SHA256 for EVERY node's otype, non-slot oslots and full ordered levUp tuple; prevent accidental CFM misses/fallback and silently dropped features. Compare to native exact fingerprint and full features inventory. Report warm OS/page cache effects; no statistical certainty inferred from N=3. No compiled artefacts or text payload published.
