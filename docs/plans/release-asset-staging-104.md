# Plan: auditable software prerelease publication (#104)

1. **RED-first.** Add focused synthetic artifact tests before production code. Require one wheel, one sdist, one rebuilt wheel, exact versioned names, safe archive inventories, matching actual `oraec_tf/` resource bytes across direct and sdist-rebuilt wheels, and manifest SHA256/size/source revision. Negative cases: changed app/schema bytes, wrong version, extra raw corpus member and fake/distinct rebuilt wheel.
2. Implement a short stdlib `scripts/verify_release_assets.py` composing the existing archive allowlist (no extraction), verifying real zip payloads and writing a narrow JSON digest manifest, without runtime dependencies.
3. Add `.github/workflows/software-release.yml`. PRs touching release code execute a **dry-run staging job** on their exact head (actual wheel/sdist/rebuilt wheel, verifier, no release/upload of corpus). Manual `workflow_dispatch` requires a **pre-existing tag** and checks tag name vs `pyproject.toml`, tagged SHA == current `main` HEAD and remote tag unchanged; reruns local code tests and artifact verifier; publishes only wheel/sdist/manifest if all required existing exact-SHA upstream workflows passed. Never publish on PR, never auto-create or replace release/tag.
4. Explicitly check `ci.yml` push, `writer-validation.yml` dispatch, `release-rehearsal.yml` dispatch and `agora-materializer.yml` dispatch success on the tagged SHA. If one is absent, release must refuse. Keep this check in a standalone testable script (no GH credentials in tests).
5. Exact-head Ruff/mypy/pytest 3.11–3.13, dry-run artifact build, installed-wheel distribution checks as triggered, full native source and Context-Fabric where invoked. Adversarially inspect real build logs, archived members, publication event/permissions and sha validation. Merge only after independent review. Keep issue #12 open until software prerelease is truly published and an independent consumer install from those published bytes passes.
6. No new serializer/cache/service, data distribution or changes to the Egyptian graph.
